# 寰宇征服 MapConquer

Android 上的六角格回合制大戰略遊戲。自由軟體，沒有廣告、沒有追蹤，
而且**完全不要求任何權限** —— 它不連網、不讀寫外部儲存、也不取位置。

兩個模式：

- **戰役** —— 三章（二戰歐洲、二戰太平洋、冷戰），九場戰役，從 1939 年的波蘭
  打到 1985 年的中歐前線。每一場兩邊都能打，各有各的目標：攻下指定城市，
  或堅守到指定回合。愈快獲勝星等愈高；星等換成勳章，勳章招募的指揮官之後每一局都能用。
- **征服** —— 1939、1943、1950 或 1980 年的整個世界，當年的陣營都已經劃好。
  攻下所有跟你交戰的國家的全部城市；盟國與中立國不算。丟掉最後一座城的國家
  會投降：它剩下的部隊全部消失，剩下的領土歸攻下那座城的一方。

每一輪都由你先動，AI 在你之後行動。

正體中文、简体中文、English，可以在 app 內切換。

## 這款遊戲真正模擬了什麼

| 系統 | 說明 |
| --- | --- |
| 地圖 | 尖頂六角格，軸向座標做數學、奇數列偏移做儲存。世界地圖 120×76，東西環繞。地圖刻意變形 —— 歐洲與東亞放大、大洋壓扁 —— 但地理關係是真的：哪些國家接壤、哪些之間隔著海，每次產生地圖時都會檢查。 |
| 地形 | 13 種，各有移動成本、防禦加成與產值。輪車與履帶進不了山地、叢林與沼澤。 |
| 領土 | 歸屬算在**省**上而不是格上，一省就是一座城與它的土地。城防被打光、陸軍站進城裡，這座城就陷落，整省跟著易主。香港、直布羅陀、貝爾法斯特是只佔一格的據點。 |
| 兵種 | 17 種：陸軍 11、海軍 6。每種都有四個獨立的攻擊值 —— 對步兵、對裝甲、對艦艇、對空 —— 所以「派誰去」比「數字多大」更重要。部隊建造時就決定編制，一到四個。 |
| 空軍 | 不是棋盤上的棋子，而是花錢買的任務：戰鬥機打擊、轟炸機打擊（也能轟炸無人城市的城防）與空降，從城市與航艦起飛（轟炸機要大城市）。附近的防空、巡洋艦、驅逐艦會削弱打擊。 |
| 戰鬥 | 攻防比公式（`55·A/(A+D)`），天然有界，加上 ±8% 的決定性亂數。火炮遠射不被反擊，但被貼身幾乎無法自衛。城裡的部隊只受一半傷害，城防另外承受這一擊的 70%。 |
| 控制區 | 走到敵人旁邊就必須停下。裝甲部隊每次移動可以無視一次，這正是它作為突破口的價值。 |
| 補給 | 從自己的城市沿自己的領土擴散，用移動成本計價 —— 所以越過山脈的攻勢會比沿平原推進更快斷補。斷補給會先掉戰力，最後餓死。補給車與司令部自帶一個小型補給圈。 |
| 經驗 | 部隊靠打出的傷害與擊殺從 1 級升到 5 級。 |
| 指揮官 | 16 位虛構指揮官，技能可疊加。用戰役星等換來的勳章解鎖，之後每一局都能用。 |
| 研發 | 六個分支，各五級，每級 +8%。 |
| 外交 | 各陣營在史實的回合參戰；你可以對中立國宣戰，它就成了你也必須打垮的敵國。停戰冷卻避免 AI 反覆開關戰爭。 |
| AI | 難度只調資源，規則跟玩家完全一樣。AI 寫成可分段執行的狀態機，所以一百多個國家輪流行動也不會卡住畫面。 |

## 建置

除了 JDK 17 之外不需要另外裝東西，其餘由 Gradle 抓。

```bash
./gradlew assembleRelease
```

產出的是 `app/build/outputs/apk/release/` 底下未簽章的 APK。跑測試（很值得跑，理由見下）：

```bash
./gradlew test
```

## 發行與簽章

Release APK 用本專案自己的金鑰簽章，而且建置必須**可重現**：同一個 commit 從原始碼
建出來的未簽章 APK 必須位元相同，F-Droid 才能拿它自己建的版本跟我們的比對，
然後發布我們簽的那一份。這樣所有人拿到的都是同一個簽章，在 F-Droid、GitHub Releases
與其他商店之間切換都不必重裝。

CI（`.github/workflows/build.yml`）每次 push 都會：

1. 在沒有任何簽章設定的情況下建出 release APK —— 就是 F-Droid 會建出來的那一份；
2. 用 `apksigner` 簽章，金鑰來自 repo secret `RELEASE_KEYSTORE`（base64），
   密碼與別名來自 `RELEASE_KEYSTORE_PASSWORD`、`RELEASE_KEY_ALIAS`、
   `RELEASE_KEY_PASSWORD`，並印出憑證指紋；
3. 另一個 job 從兩個不同的目錄各建一次 release，兩份不一致就讓建置失敗。

簽章憑證 SHA-256：

```
CE:85:A4:91:84:50:57:7B:3B:59:42:3E:A7:62:CC:86:76:E2:25:2C:6F:28:02:6A:C0:BB:B9:13:FC:4F:06:A0
```

發行新版本：

1. 在 `app/build.gradle.kts` 調高 `versionCode` 與 `versionName`；
2. 在 `fastlane/metadata/android/*/changelogs/<versionCode>.txt` 寫好這一版的更新說明；
3. commit，然後把那個 commit 標上 `v<versionName>` 並推上去：

   ```bash
   git tag v0.1.0
   git push origin v0.1.0
   ```

CI 會檢查 tag 跟 `versionName` 一致、更新說明存在，跑完上面所有檢查，
然後建立一個 GitHub Release，附上簽好章的 `mapconquer-<versionName>.apk`，
說明文字就是那份更新說明。

## 測試

整個模擬層 —— 六角數學、尋路、地圖與劇本解析、戰鬥、回合引擎與 AI ——
完全沒有相依任何 Android API。這是刻意設下的架構限制，換來的好處是：
它們可以在一般的 JVM 上，用**正式出貨的**地圖與劇本跑測試，而不是餵假資料。

- `HexMathTest` —— 座標往返、環與圓盤的大小、直線的連續性。
- `PathfinderTest` —— Dijkstra 範圍、考慮成本的繞路、控制區、以及搜尋之間不殘留狀態。
- `MapAssetTest` —— 每一張地圖都解析得動；鄰接關係對稱；每一格陸地都屬於某個含有自己
  省會的省；世界地圖上的海峽從頭到尾都是水；改動任何一格，地圖指紋就會跟著變。
- `ScenarioAssetTest` —— 每份劇本都對照它的地圖驗過：沒有省份被兩國同時宣稱、
  沒有軍艦生在陸地上、沒有「開局就已經持有」的戰役目標。
- `CombatTest` —— 傷害邊界、兵種相剋、地形與築壕、火炮的不對稱性。
- `SessionTest` —— 在手寫的小地圖上驗回合引擎：佔領、圍城、編制、空中任務、投降、
  征服的勝利條件與回合上限，以及新局一開始就輪到玩家。
- `ConquestSmokeTest` —— 載入真實的世界地圖與一百多個國家，讓 AI 操控每一方
  完整跑好幾個回合，每回合結束後檢查一整組狀態不變量。

## 產生出來的內容

地圖、劇本與三份 `strings.xml` 都是**產生**的，產生器在 `tools/`：

```bash
python3 tools/genworld.py     # → app/src/main/assets/{maps,scenarios}
python3 tools/genstrings.py   # → app/src/main/res/values*/strings.xml
```

- `tools/geodata.py` —— 海岸線、山脈、沙漠、雨林與河流，全部是手繪的經緯度多邊形。
  這些是原創的簡化輪廓，**不是**從 OpenStreetMap、Natural Earth 或任何資料庫轉出來的：
  在這個尺度下真實資料換不到任何差別，而整包只有一種授權，F-Droid 的稽核也就變得單純。
  這裡也列出哪些陸塊之間絕對不能相連（各個島嶼，以及阿拉伯半島對非洲這類配對）。
- `tools/hexraster.py` —— 把那些多邊形投影到六角格上，確保每座島、每道海峽至少隔一格海，
  再依緯度、高程與生態帶塗上地形。
- `tools/places.py` —— 省份與國家的唯一資料來源：一列一座城市，帶座標、城市等級、
  歸屬國，以及三種語言的名字；還有各年份國家怎麼合併、分裂、結盟。地圖檔與翻譯都由
  這張表產生，所以兩邊永遠不會走鐘。
- `tools/scenarios.py` —— 戰役關卡的定義。
- `tools/topology.py` —— 把地理寫成規則：必須存在的國界、必須是海的海峽、本土必須連成
  一片的國家。世界地圖違反任何一條，`genworld.py` 就會失敗。

CI 會重跑兩支產生器，只要輸出跟 commit 的版本有差就讓建置失敗 ——
repo 裡的資產永遠對得上產生它的工具。

## 設計筆記

讀程式碼之前值得先知道的幾個決定：

- **畫面全部畫在 `Canvas` 上。** 一個 Activity、一個 SurfaceView，
  沒有 Compose、沒有 Fragment、沒有 View 樹。每個頁面都是 `GameView` 的一個狀態。
- **沒有任何二進位素材。** 兵種記號是向量畫的、圖示是向量、國旗是 emoji、音效是即時合成的。
  APK 裡沒有一樣東西需要交代來源。
- **決定性。** 亂數是帶種子的 xorshift，狀態本身就是存檔的一部分，
  所以讀檔之後同一場仗會打出同樣的結果。
- **存檔認得自己的地圖。** 存檔記下地圖指紋與格式版本；在另一張地圖、或舊版規則下
  建立的存檔會被拒絕，而不是讀進錯的格子裡。
- **用格子索引而不是物件。** 尋路與 AI 每回合要走過數十萬個格子，
  那條路徑上不做任何配置。
