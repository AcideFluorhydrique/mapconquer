# 寰宇征服 MapConquer

Android 上的六角格回合制戰略遊戲。你指揮一個國家的軍隊 —— 步兵、戰車、火炮、軍艦與飛機 ——
攻下城市、顧好補給，一省一省把仗打贏。

自由軟體，沒有廣告、沒有追蹤，而且**完全不需要任何 Android 權限**：它不連網、不讀你的
儲存空間、也不碰你的位置。正體中文、简体中文、English，可以在 app 內切換。

[English](README.md)

## 可以玩什麼

**戰役。** 三個章節、九場歷史戰役 —— 二戰歐洲、二戰太平洋、冷戰 —— 從 1939 年的波蘭打到
1985 年的中央戰線。每一場都可以選任一邊來打，目標都很明確：攻下指定的城市，或是把它們
守到指定的回合。贏得越快星星越多，星星可以換指揮官，之後每一局都能用。

**征服。** 整個世界，從你選的年份開始：

- **1939** 與 **1943** —— 軸心國對同盟國。
- **1950** —— 西方陣營對東方陣營。
- **1980** —— 架空歷史。一支不屬於任何國家的軍隊「灰燼軍團」拿下了世界的大半，
  十六個倖存的國家各自只剩幾座城，聯手反攻。

選一個國家，打垮所有跟你交戰的國家。一個國家丟掉最後一座城就投降。

## 一回合怎麼玩

你先動；你結束回合之後才輪到電腦。

- **移動與攻擊。** 點一支部隊。藍色格是它走得到的地方，紅色格上有它打得到的敵人。
  攻擊過的部隊這回合不能再移動。
- **攻下城市。** 城市有自己的城防。先把城防打到零，再讓一支陸軍走進去，
  整個省連同它的收入就是你的。
- **生產。** 點自己的城市，按「生產」。越大的城市造得出越重的裝備。
  部隊可以一次造成一到四個編制。
- **顧好補給。** 補給從你和盟友的城市往外延伸。離開補給範圍的部隊會變弱，最後餓死。
  打開「補給」圖層看得到範圍；補給車可以把補給帶到前線。
- **動用空軍。** 點一座大一點的城市或一艘航艦，按「空軍」。戰鬥機打步兵，
  轟炸機打戰車與軍艦，空降可以把步兵放到敵後。
- **渡海。** 部隊可以自己涉水過海峽，但真的要跨海就讓它們搭運輸艦 —— 而且要護航。
- **看顏色。** 金色是你自己，綠色是盟友，紅色是敵人，灰色是中立。粗的紅色國界就是戰線。

遊戲裡的「遊戲說明」對每一項都有更詳細的解釋。

## 兵種一覽

不必背。只要記得一件事：每種部隊都有擅長打的和不擅長打的，派對的去就好。

| 陸軍 | 用來做什麼 |
| --- | --- |
| 步兵 | 便宜又耐打。攻城與守城靠的就是它。 |
| 山地步兵 | 在山地與叢林裡走得快的步兵。 |
| 陸戰隊 | 唯一能下船之後同一回合就開打的部隊。 |
| 偵察車 | 跑得很快、看得很遠，但很脆。用來找敵人。 |
| 裝甲 | 火力強，能突破敵人的防線，擊毀目標之後還能再打一次。 |
| 反坦克炮 | 專門打戰車。打別的東西很弱。 |
| 火炮 | 從兩三格外開火，不會被反擊。被貼身就沒辦法還手。 |
| 火箭炮 | 射程更遠、火力更猛的火炮，也更貴。 |
| 防空炮 | 削弱附近敵方的空襲與空降。 |
| 補給車 | 把補給帶到前線，攻勢才推得下去。 |
| 司令部 | 強化附近的友軍，同時替它們補給。 |

| 海軍 | 用來做什麼 |
| --- | --- |
| 運輸艦 | 載三支陸軍過海。沒有武裝 —— 要護航。 |
| 驅逐艦 | 便宜的護航艦。專門獵殺潛艇。 |
| 巡洋艦 | 全能的軍艦，還能替附近的船擋空襲。 |
| 戰艦 | 最強的軍艦。可以從三格外砲擊海岸。 |
| 潛艇 | 靠近之前看不見。運輸艦的剋星。 |
| 航空母艦 | 移動的機場：每回合可以出擊一次空中任務。 |

| 空中任務 | 用來做什麼 |
| --- | --- |
| 戰鬥機出擊 | 重創步兵。 |
| 轟炸機出擊 | 重創戰車與軍艦，也能炸空城的城防。只能從大城起飛。 |
| 空降 | 在航程內空著的陸地格放下一支新的步兵。 |

## 安裝與建置

簽好名的 APK 放在 [GitHub Releases](https://github.com/AcideFluorhydrique/mapconquer/releases)。

自己建置只需要 JDK 17，其餘的 Gradle 會自己抓：

```bash
./gradlew assembleRelease
```

貢獻者需要的其他東西 —— 規則細節、測試、發行簽章、地圖產生器與設計筆記 ——
都在 [docs/development.zh.md](docs/development.zh.md)。

## 參考行為

許多規則 —— 戰鬥、勝利條件、投降、回合順序、1980 年征服的格局 —— 參照的是同類型一款
經典遊戲的行為，依據是維護者自己對它的遊玩與分析。已經確認的、還不確定的、以及可以
怎麼驗證，都寫在 [docs/original-behavior.md](docs/original-behavior.md)。

那份文件記錄的是行為，以及定義那些行為的數字。這裡的程式碼是依照那些描述獨立寫成的，
本專案不包含那款遊戲的任何東西 —— 沒有程式碼、美術、音效、地圖或文字。寰宇征服刻意
不一樣的地方（補給線、維持費、自己的兵種表與地圖），文件裡也都有註明。
